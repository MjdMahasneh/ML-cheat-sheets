# Git & GitHub Commands Cheatsheet

---

## 1. Repository Setup
- Initialize: `git init`
- Clone: `git clone <url>`

---

## 2. Staging & Commit
- Stage: `git add <file>` or `git add .`
- Commit: `git commit -m "message"`

---

## 3. Branching
- List: `git branch`
- Create: `git branch <name>`
- Switch: `git checkout <name>`
- New & switch: `git checkout -b <name>`

---

## 4. Merging
- Into current: `git merge <branch>`
- Resolve conflicts if any.

---

## 5. Remote
- Add: `git remote add origin <url>`
- Push: `git push -u origin <branch>`
- Pull: `git pull`

---
