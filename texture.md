# Texture Analysis Cheatsheet

---

## 1. Local Binary Patterns (LBP)
- Compute LBP code per pixel: compare neighbors to center.
- Histogram of LBP codes for texture descriptor.

---

## 2. Gray-Level Co-occurrence Matrix (GLCM)
- GLCM(d, θ): count pixel pairs with intensity values.
- Features: contrast, correlation, energy, homogeneity.

---

## 3. Gabor Filters
- Kernel: Gaussian-modulated sinusoid.
- Multi-scale, multi-orientation responses.

---

## 4. Wavelets
- Discrete wavelet transforms (e.g., Haar, Daubechies).
- Multi-resolution analysis.

---

## 5. Applications
- Classification, segmentation, defect detection.
